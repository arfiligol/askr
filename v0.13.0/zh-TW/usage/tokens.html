樣式變數

Askr 提供編譯時使用的 Sass 預設值，以及供建置後頁面使用的 --qdk-* CSS 屬性。使用者樣式應放在 Askr 之後；請勿修改已安裝的擴充套件檔案。分頁切換、收合、導覽、搜尋與複製仍由 Quarto 原生功能負責；樣式變數只改變呈現方式。

讀者主題切換按鈕會使用 Askr 的控制項尺寸、邊框、圓角、顏色與游標移入樣式。Askr 會在搜尋旁預留該控制項的空間，因此使用者不必依賴內部的 --_qdk-* 縮放屬性另外調整間距。

在使用專案中覆寫

format:
  askr-html:
    theme:
      light: [default, _extensions/arfiligol/askr/qdk.scss, styles.scss, light.scss]
      dark: [default, _extensions/arfiligol/askr/qdk.scss, _extensions/arfiligol/askr/qdk-dark.scss, styles.scss, dark.scss]

使用 scss:defaults 可變更編譯後的 Quarto 樣式及其衍生 CSS 屬性。下表中的 Sass 預設值皆使用 !default；使用者指派值時不需加上它。Quarto 會以反向順序讀取主題清單中的預設值，再依正向順序套用規則。共用預設值放在 styles.scss，各主題專用的預設值放在 light.scss / dark.scss；同一主題中的每個變數只能指派一次。較後面的檔案不會覆寫較前面的無條件 Sass 指派，因為預設值會先執行。

例如，light.scss 可包含 $body-bg: #f3f5f7;，dark.scss 可包含 $body-bg: #20252b;，並都放在 /*-- scss:defaults --*/ 區段中。使用這種配置時，不要在共用檔案中設定 $body-bg。共用的 styles.scss 可包含：

/*-- scss:defaults --*/
$link-color: #2d5e85;
$grid-body-width: 680px;
$qdk-tab-size: .85rem;
$qdk-tab-padding-y: .3rem;

/*-- scss:rules --*/
:root {
  --qdk-callout-radius: 8px;
  --qdk-table-cell-padding: .35rem .7rem;
}

CSS 覆寫會影響使用該屬性的規則；Sass 覆寫也會影響由該 Sass 變數編譯而成的 Quarto 原生規則。像 --qdk-tab-active-border: var(--qdk-link) 這類元件別名，會跟著全域基礎值變化，除非使用者另行覆寫該元件。CSS 值必須符合目標屬性的語法；若編譯期輸入無效，Quarto 會在編譯時回報。

自適應基準

公開基準不會在視窗規則中重新指派。Askr 會乘上內部倍率；--_qdk-* 屬性屬於實作細節。這能在各種寬度保留使用者設定的基準，以及預設版面幾何：

視窗寬度（px） 內文 側欄／邊界 欄間距 根字級 UI 倍率
小於 630 符合容器寬度 264px 26px 16px 1.02
630–991.98 符合容器寬度 264px 26px 18px 1.15
992–1279.98 630px 200px 16px 17px 1.08
1280–1439.98 630px 240px 22px 17px 1.08
1440–1919.98 630px 264px 26px 18px 1.15
1920–2559.98 693px 290px 29px 20px 1.27
2560 以上 756px 320px 31px 22px 1.4

例如，680px 內文基準在 1920px 視窗寬度會變成 748px（×1.1），在 2560px 時則變成 816px（×1.2）。行動版內容會符合可用容器寬度。網站選項 askr.reading-width: wide 會將一般基準換成 780px，因此在 1920px 時為 858px，在 2560px 時為 936px。固定、浮動或不存在的側欄都會使用選定的閱讀欄寬度。Quarto 原生寬度擴展與閱讀模式仍保有原有行為。

低於 992px 時，提示框水平內距與標題內距會使用 ×.8。分頁標籤預設維持 .9rem 字級與 .35rem 垂直內距，隨根字級縮放，不會被另一組分頁尺寸取代。
