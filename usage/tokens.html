Tokens

Askr exposes Sass defaults for compilation and --qdk-* CSS properties for the rendered page. Consumer styles belong after Askr; keep installed extension files unchanged. Native Quarto owns tab switching, collapse, navigation, search and copying; tokens change presentation.

Override in the consumer

format:
  askr-html:
    theme:
      light: [default, _extensions/arfiligol/askr/qdk.scss, styles.scss, light.scss]
      dark: [default, _extensions/arfiligol/askr/qdk.scss, _extensions/arfiligol/askr/qdk-dark.scss, styles.scss, dark.scss]

Use scss:defaults to change compiled Quarto styles and their derived CSS properties. All listed Sass defaults use !default; consumer assignments omit it. Quarto reads defaults in reverse theme-list order and rules in forward order. Put shared defaults in styles.scss and theme-specific defaults in light.scss / dark.scss; each variable must have only one consumer assignment per theme. A later file does not override an earlier unconditional Sass assignment because its defaults run first.

For example light.scss contains $body-bg: #f3f5f7; and dark.scss contains $body-bg: #20252b;, each under /*-- scss:defaults --*/. Keep $body-bg out of the shared file in that arrangement. The shared styles.scss can contain:

/*-- scss:defaults --*/
$link-color: #2d5e85;
$grid-body-width: 680px;
$qdk-tab-size: .85rem;
$qdk-tab-padding-y: .3rem;

/*-- scss:rules --*/
:root {
  --qdk-callout-radius: 8px;
  --qdk-table-cell-padding: .35rem .7rem;
}

CSS overrides affect rules that consume the property. Sass overrides also reach native Quarto rules compiled from that Sass variable. A component alias such as --qdk-tab-active-border: var(--qdk-link) follows changes to its global base unless the consumer overrides the component itself. CSS values must be valid for their target CSS property; Sass compilation reports invalid compile-time inputs through Quarto.

Dark overrides divider-content to rgba(212,212,212,.24), divider-layout to rgba(212,212,212,.10), and mark to #b3aa0288. Other component defaults are shared between themes and follow palette aliases. Dark code-color follows var(--qdk-text); inline code keeps the heading color. Native Quarto tables use .5rem header and cell padding and a 1px header border, with the existing muted header-border color. These defaults retain the observed native baseline: earlier Askr padding and 2px header-width declarations were overridden by Bootstrap; the muted color already applied. The token rules now address native table cells directly; plain HTML tables consume the same defaults. The header border token controls color, while border width remains 1px. --qdk-callout-color is the local resolved type color of each native callout; override a named type color to change all callouts of that type.

Responsive bases

Public bases are never reassigned in viewport rules. Askr multiplies them by internal factors; --_qdk-* properties are implementation details. This preserves consumer bases at every width and retains the default geometry:

Viewport width (px) Body Sidebar / margin Gutter Root type UI multiplier
below 630 fits container 264px 26px 16px 1.02
630–991.98 fits container 264px 26px 18px 1.15
992–1279.98 630px 200px 16px 17px 1.08
1280–1439.98 630px 240px 22px 17px 1.08
1440–1919.98 630px 264px 26px 18px 1.15
1920–2559.98 693px 290px 29px 20px 1.27
2560 and above 756px 320px 31px 22px 1.4

For example a 680px body base becomes 748px at 1920px (×1.1) and 816px at 2560px (×1.2). Mobile content fits the available container. Callout horizontal/header padding uses ×.8 below 992px. Tab labels stay .9rem with .35rem vertical padding by default, scaling with the root type rather than being replaced by another tab size.
